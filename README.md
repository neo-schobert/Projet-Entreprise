# Outil d'Analyse de Pollution des Eaux avec Sentinel-1

## Description
Ce projet détecte la pollution des eaux à partir d'images satellites de Sentinel-1. Il permet de sélectionner une zone géographique, récupérer les données satellites et analyser ces données.

## Fonctionnalités
- **Sélection de la Zone**: Interface pour définir la zone géographique à analyser.
- **Récupération des Données**: Téléchargement automatique des données satellites de Sentinel-1 pour la zone sélectionnée.
- **Analyse des Données**: Traitement et analyse des images pour détecter les signes de pollution des eaux.

## Prérequis
- Python 3.7 ou supérieur
- `requirements.txt` pour les dépendances

## Installation
```sh
git clone https://github.com/votre-repo/outil-analyse-pollution.git
cd outil-analyse-pollution
pip install -r requirements.txt
```
